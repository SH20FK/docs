# PaxGame.main уходит — чем заменить

`PaxGame.main` (прямой доступ к главной сцене) закрывается через два обновления. Сейчас он работает, но при первом обращении пишет предупреждение в журнал Pax. Переходите на методы `PaxGame` — они не меняются от обновления к обновлению.

Нет нужного метода — напишите в #моддинг, добавим в API.
