# 01 · Устройство мода, загрузка, публикация

[← К руководству](README.md)

## Мод — это папка

```
mods/
  my_mod/
    mod.json                 обязательно — описание мода
    thumbnail.png            картинка 256×256 для лаунчера (по желанию)
    main.gd                  код, `extends PaxMod` (по желанию)
    data/
      bodies.patch.json      правки data/bodies.json игры
      crises.patch.json      … любого файла данных
      prompt_talk.append.txt текст, дописываемый к промпту игры
      lang/ru.json           переводы (сливаются со словарём игры)
      lang/en.json
    planets/xeno_albedo.png  ваши файлы: где угодно, как угодно названы
    shaders/aurora.gdshader
    models/station.glb
    music/надежда_mymod.ogg
    presets/Мой мир/meta.json  готовый пресет мира
```

Всё внутри мода доступно как **`res://mods/<id>/…`** — в JSON (`"map": "res://mods/my_mod/planets/xeno"`),
в коде (`path("planets/xeno_albedo.png")` или `load("res://mods/my_mod/scene.tscn")`) и в `preload`.

## Где лежат моды

| Где | Когда |
|---|---|
| `<папка игры>/mods/` | выпущенная игра (рядом с `PaxUniverse.exe`) |
| `<проект>/mods/` | запуск из редактора Godot (в папке `.gdignore`, Godot её не импортирует) |
| `%APPDATA%/Godot/app_userdata/Terraform Prototype/mods/` (`user://mods/`) | моды конкретного пользователя |

Мод — **папка** или **.zip** (с `mod.json` в корне или в единственной папке внутри).
Папки, начинающиеся с `_` или `.`, пропускаются (`_template` — шаблон для команды `new`).
Команда консоли `folders` покажет точные пути.

## mod.json

```json
{
  "id": "my_star_cluster",
  "name": {"en": "Pleiades Cluster", "ru": "Скопление Плеяды"},
  "version": "1.2.0",
  "api": 1,
  "game_version": ">=0.9.0",
  "authors": ["Ваше имя"],
  "description": {"en": "Seven young stars 444 light years away.", "ru": "Семь молодых звёзд в 444 св. годах."},
  "tags": ["star system", "arks"],
  "depends": ["base_arks_overhaul>=2.0"],
  "load_after": ["some_optional_mod"],
  "load_before": [],
  "entry": "main.gd"
}
```

| Поле | Значение |
|---|---|
| `id` | **Обязательно.** `a-z 0-9 _ - .`, 2–64 знака. Не меняйте после выхода: на id ссылаются сейвы и другие моды. |
| `name`, `description` | Строка или `{"en": …, "ru": …, "de": …}` — лаунчер берёт язык игрока, потом английский. |
| `version` | Версия мода (`1`, `1.2`, `1.2.3`). |
| `api` | Версия Pax API, под которую написан мод. Сейчас **1**. Больше — предупреждение. |
| `game_version` | Минимальная версия игры, например `">=0.9.0"`. |
| `depends` | Моды, без которых этот не работает (`"id"` или `"id>=1.2"`). Грузятся раньше. Включили мод в лаунчере — включатся и они. |
| `load_after` / `load_before` | Мягкий порядок относительно модов, которые могут и не стоять. |
| `entry` | Файл GDScript с `extends PaxMod`. Для модов только с данными — не указывайте. |
| `client_only` | `true` — мод только меняет вид (текстуры, музыка, шрифты) и не влияет на игру. Такой мод не сверяется в сетевой партии: игрок может играть с ним, даже если у хоста его нет. Всем остальным модам в сетевой партии нужен тот же набор и те же версии, что у хоста. |
| `tags` | Метки в лаунчере; `planet`, `star`, `ark`, `character`, `shader`, `music`, `language`, `ui` выбирают значок-заглушку. |

Схема с автодополнением: [`../schemas/mod.schema.json`](../schemas/mod.schema.json)
(добавьте `"$schema": "../../docs/modding/schemas/mod.schema.json"` или возьмите `.vscode/settings.json` из шаблона).

## Порядок загрузки

1. Зависимости и `load_after`/`load_before` — соблюдаются всегда.
2. Дальше — порядок, который игрок выставил в лаунчере (▲▼).
3. Дальше — по алфавиту id.

**Позже — главнее:** замены позднего мода перекрывают ранние, его правки ложатся сверху.
Лаунчер показывает место `#1, #2…`, команда `mods` печатает порядок.

## Включить, выключить, порядок

Лаунчер → **Моды**: галочки, ▲▼ порядок, «Включить все / Выключить все», «Папка модов», «Как делать моды».
Галочка действует **сразу, без перезапуска**: лаунчер перечитывает моды, подключает файлы новых, у выключенных
выгружает код (вызывается `_mod_unloaded()`). Перед «Играть» лаунчер ещё раз перечитывает папку модов — так
подхватятся и правки, сделанные руками, пока он был открыт.
Выбор хранится в `user://mods.json` (`disabled`, `order`).

## Что видит игрок

На карточке мода: картинка, название, версия, авторы, описание, метки, чип **⚙ свой код** у модов со скриптами
(с предупреждением ставить моды только от тех, кому доверяешь), зависимости и все проблемы загрузки (на языке игрока).
Моды, которые не удалось прочитать совсем, показаны отдельной карточкой.

## Публикация

- `pack <id>` в консоли F8 или `godot --headless --path <игра> -- --pack-mod <id> [папка]` — сначала проверяет мод,
  потом пишет `<id>-<версия>.zip` без служебных `.import`/`.uid` Godot.
- Игрок ничего не распаковывает: zip кладётся в `mods/` как есть.
