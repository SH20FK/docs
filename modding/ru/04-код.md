# 04 · Код: геймплей, интерфейс, что угодно

[← К руководству](README.md) · [Справочник API (англ.)](../en/api-reference.md)

Правки данных меняют, *что* есть в игре. Код меняет, *как она себя ведёт*. Код мода — GDScript, тот же язык, на
котором написана игра; он работает внутри игры с полным доступом.

```json
// mod.json
{"id": "my_mod", "entry": "main.gd"}
```
```gdscript
# main.gd
extends PaxMod

func _world_ready(game: PaxGame) -> void:
    game.toast("Привет от моего мода!")
```

API называется по-английски, как принято у движков: так его поймёт любой разработчик и любой ИИ-ассистент.
Внутренности игры — по-русски.

## Три объекта

| Объект | Что это | Как получить |
|---|---|---|
| **`PaxMod`** | Базовый класс вашего `main.gd`: колбэки и помощники (`path`, `texture`, `tr_key`, `log_info`, настройки). | `extends PaxMod` |
| **`PaxGame`** | Идущая игра: время, тела, системы, ресурсы, колонии, фракции, персонажи, корабли, интерфейс, 3D-сцена. **Стабильный API.** | аргумент `game` колбэков или `Pax.game` |
| **`Pax`** | Автозагрузка: сигналы для любых скриптов, данные с правками модов, другие моды, команды консоли. | `Pax` откуда угодно |

Узел мода живёт всё время работы процесса: создаётся при старте (в лаунчере) и переживает переходы между лаунчером
и мирами. `Pax.game` равен `null`, пока мир не загружен.

## Колбэки

| Колбэк | Когда |
|---|---|
| `_mod_loaded()` | Старт игры, мира ещё нет. Команды консоли, чтение настроек. |
| `_mod_unloaded()` | Мод выключили в лаунчере (без перезапуска). Уберите то, что сделали в `_mod_loaded`. |
| `_game_loaded(game, state)` | Открывается сейв; `state` — то, что вернул `_save_state`. **До** `_world_ready`. |
| `_world_ready(game)` | Новая игра или сейв собраны целиком: тела, фракции, интерфейс. Интерфейс стройте здесь. |
| `_body_created(game, body)` | Каждое тело сразу после создания (до `_world_ready`). Материалы, свои узлы. |
| `_days_passed(game, from_day, days)` | Прошло время (каждая перемотка). Здесь ваши правила игры. |
| `_ship_arrived(game, ship)` | Корабль или ковчег долетел. |
| `_save_state(game) -> Dictionary` | Игра сохраняется. Верните данные JSON-типов (без Vector3 и объектов). |
| `_data_reloaded()` | Команда `reload`: перечитайте свой JSON. |

Те же моменты — **сигналы** `Pax` (`world_ready`, `days_passed`, `body_created`, `saving`, `loaded`,
`ship_launched`, `ship_arrived`, `data_reloaded`, `mods_loaded`), удобно из сцен и вспомогательных скриптов:
```gdscript
Pax.days_passed.connect(func(game, from_day, days): print(days))
```

## Правило игры в 15 строк

Солнечные бури: раз в ~5 лет случайная колония теряет энергию.

```gdscript
extends PaxMod

var _years := 0.0

func _days_passed(game: PaxGame, _from: int, days: int) -> void:
    _years += days / 365.25
    while _years >= 5.0:
        _years -= 5.0
        var colonies := game.colonies()
        if colonies.is_empty():
            return
        var hit: String = colonies[randi() % colonies.size()]
        game.add_resource(hit, "energy", -40.0)
        game.chronicle(hit, tr_key("my_mod_storm") % game.tr_key("body_" + hit), "bad", 3)

func _save_state(_g: PaxGame) -> Dictionary:
    return {"years": _years}

func _game_loaded(_g: PaxGame, state: Dictionary) -> void:
    _years = float(state.get("years", 0.0))
```

Ресурсы: `люди`, `энергия`, `стройматериалы`, `вода`, `еда`, `горючее`, `редкое`. Тон хроники: `good`, `bad`, `mixed`, `neutral`.

## Хуки: вмешаться в решение игры

Колбэки выше говорят, что случилось. Хуки дают **поменять** то, что игра вот-вот сделает: приказ, объявление войны, закон, выборы, итоги перемотки, запрос к нейросети. Полный список со всеми полями — [hooks.md](hooks.md), он собирается из кода.

```gdscript
extends PaxMod

func _mod_loaded() -> void:
    # Пацифистский мир: войну объявить нельзя.
    hook("war_declared", func(d):
        d.cancel = true
        Pax.game.toast(tr_key("my_mod_no_war")))
    # Каждый принятый закон — запись о бумажной волоките в хронике.
    hook("law_passed", func(d):
        Pax.game.chronicle(Pax.game.home_body(), tr_key("my_mod_paperwork"), "mixed", 1))
    # Приказы в этом мире идут вдвое быстрее.
    hook("order_parsed", func(d):
        d.request["days"] = maxi(1, int(float(d.request.get("days", 30)) / 2.0)))
```

- Обработчик получает один словарь `d` и меняет его на месте. Можно вернуть словарь — он вольётся в `d`.
- У хуков с пометкой **[cancel]** `d.cancel = true` отменяет действие; остальные моды после этого не вызываются.
- `hook(имя, обработчик, приоритет)`: больший приоритет вызывается раньше.
- Записи игры внутри (`d.law`, `d.faction`, `d.research`) — с русскими ключами, как в `data/*.json`.
- Выгрузили или перезагрузили мод (F6) — его хуки снимаются сами.

### Добавить правила во все запросы к нейросети

```gdscript
hook("ai_request", func(d):
    if d.channel in ["interpreter", "report", "faction"]:
        d.system += "\n\nIn this world magic is real and costs blood.")
```

Дописывайте в **конец** `d.system`: начало запроса кэшируется провайдером, и правка в начале сделает каждый запрос дороже.

## Нейросеть из мода

`ask_ai(канал, промпт, данные, готово, настройки)` — свой запрос со своим промптом. Игра сама добавит лор мира, правила и язык игрока, учтёт расход (в статистике он виден как `mod_<id>_<канал>`) и вернёт разобранный JSON.

```gdscript
func спросить_оракула() -> void:
    var prompt := "You are the Oracle of this world. Given the country and the date, make one short, " \
        + "unsettling prophecy. Return ONLY JSON: {\"prophecy\": \"…\"}"
    ask_ai("oracle", prompt, {"country": Pax.game.player_faction().get("name", ""), "date": Pax.game.date_text()},
        func(answer: Dictionary):
            if answer.has("prophecy"):
                Pax.game.chronicle(Pax.game.home_body(), str(answer["prophecy"]), "neutral", 2))
```

- Промпт заканчивайте примером JSON, который ждёте.
- Пустой словарь в ответе — нейросети нет, ошибка связи или предел: не больше **12 запросов в минуту** на мод.
- `настройки`: `{"temperature": 0.7, "max_tokens": 1200}`.

## Интерфейс

```gdscript
func _world_ready(game: PaxGame) -> void:
    var box := VBoxContainer.new()
    var label := Label.new()
    label.text = tr_key("my_mod_title")
    box.add_child(label)
    var go := Button.new()
    go.text = tr_key("my_mod_fly")
    go.pressed.connect(func(): game.focus("Марс"))
    box.add_child(go)
    game.add_window(tr_key("my_mod_button"), box, Vector2(340, 200))
```

- `add_window(текст_кнопки, содержимое, мин_размер)` — окно над нижней панелью со своей кнопкой; закрывается,
  когда игрок открывает другое окно игры, как встроенные.
- `add_bottom_button(текст, callable)` — просто кнопка.
- `hud_layer()` — `CanvasLayer` интерфейса: любой `Control` в любом месте экрана.
- Годится любой интерфейс Godot: сцены мода (`scene("ui/panel.tscn")`), темы, анимации, `Tween`.

## Тела, системы, 3D

```gdscript
game.body_names()                      # все тела
game.body("Марс")                      # живая запись: имя, род, радиус, r_км, a_км, узел (Node3D), мат (материал), параметры…
game.set_body_param("Марс", "water", 0.5)   # климат 0..1, планета перерисуется
game.body_material("Юпитер").set_shader_parameter("band_count", 30.0)
game.focus("Титан")                    # перелёт камеры
game.set_discovered("Седна", true)
game.systems()                         # [{name, star, position_ly, mass, description}]
game.body_system("Проксима b")         # "Альфа Центавра"
game.distance_ly("Земля", "Проксима b")
```

3D: `game.body_node(имя)` — `Node3D` тела; добавленные в него дети двигаются вместе с телом (масштаб 1 = радиус тела).
Сцена со «скользящим началом координат», поэтому цепляйте объекты к телам, а не к точкам мира.
`game.scene_root()` — корень 3D, `game.camera()` — камера. Модели мода: `model("models/ship.glb")`.

## Корабли и ковчеги

```gdscript
var ship := game.launch_ship("Земля", "Проксима b", 0.1, 5000, {"cargo": "семена"}, "ark", id)
# ship: {id, откуда, куда, с_дня, до_дня, скорость_c, люди, данные, мод, …}
game.travel_days("Земля", "Проксима b", 0.1)   # ≈ 16 500 дней
game.ships()                                    # кто в пути
```

- `speed_c` — доля скорости света (0.0001…0.99). Самый короткий перелёт — 30 дней.
- Люди берутся из колонии на теле старта.
- Корабль виден летящим (модели `ковчег`, `станция`, `спутник`, `орбиталка`) и сохраняется в сейв.
- По прилёте к каменному телу: тело открывается, основывается колония (или растёт), пишется хроника, затем
  `_ship_arrived` / `Pax.ship_arrived`. Проверьте `ship["mod"] == id`, чтобы реагировать только на свои;
  `ship["data"]` — то, что вы передали.

## Персонажи

```gdscript
game.add_character("Марс", {
    "name": "Ада Рейн", "who": "начальница ледяных шахт",
    "lore": "Родилась на Марсе, Землю не видела.", "character": "сухой юмор, всё пересчитывает",
    "age": 41}, path("portraits/ada.png"), true)   # true — сразу открыть разговор
```
Нейросеть играет персонажа по этим полям. Портрет копируется в сейв (любой размер, лучше всего 256×320); без него
игра нарисует лицо или закажет портрет. На теле должна быть колония или жители.

## Что коду мода нельзя (песочница)

Перед загрузкой игра читает скрипты мода. Если в них есть запретное, мод не запускается, а в лаунчере,
студии и консоли F8 видно файл, строку и причину. Творить можно всё, что касается игры; нельзя трогать компьютер
игрока, его учётку, ключи и оплату.

| Нельзя | Чем заменить |
|---|---|
| `OS.execute`, `shell_open`, переменные окружения, системные папки | `open_link("https://…")` для ссылок |
| `HTTPRequest`, сокеты, WebSocket и прочая сеть | — (данные мода кладите в его папку) |
| `FileAccess`, `DirAccess`, `ConfigFile`, `user://`, `C:/…`, `..` | `read_text()`, `read_bytes()`, `list_files()`, `save_data()` / `load_data()`, `get_setting()` |
| `load(переменная)`, `ResourceLoader` | `load_resource("папка/файл.tscn")` или `preload("res://mods/<id>/…")` |
| `Expression`, `ClassDB`, `GDScript`, `set_script`, `str_to_var` | обычный код мода |
| `res://scripts/…`, смена сцены, `get_tree().quit()` | API: `Pax`, `game` |
| `.dll`, `.exe`, `.pck`, `.scn`, `.res`, код внутри `.tscn` | `.gd` рядом со сценой |

В игре **F6** перезагружает код и тексты модов без перезапуска.

## Полный доступ (нестабильно)

`game.main` — узел `Main` игры (`src/core/GameRoot.gd`, ~17 000 строк, русские имена), `game.sim`, `game.world`,
`game.stock` — симуляция, хроника и ресурсы. Доступно всё, но между версиями может меняться. Если что-то нужно часто —
попросите добавить это в `PaxGame`.

## Строгая типизация — прочтите один раз

В проекте «тип выведен из Variant» — это **ошибка**. Так не скомпилируется:
```gdscript
var x := some_dictionary["key"]          # ✗
var n := game.body("Марс").get("r_км")   # ✗
```
Укажите тип:
```gdscript
var x: float = some_dictionary["key"]              # ✓
var n: float = game.body("Марс").get("r_км", 0.0)  # ✓
```
`check <id>` сообщит, что скрипт не компилируется; точная строка — в выводе Godot.
