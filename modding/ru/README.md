# Моды для Pax Universe

Pax Universe сделана так, чтобы моддить её **до самого дна**. Мод может добавить планету со своими текстурами
и рельефом, целую звёздную систему или скопление звёзд с ковчегами между ними, персонажей с портретами,
события, кризисы, мегапроекты, музыку, язык, новые окна интерфейса, свои шейдеры и 3D-модели —
или совсем новый геймплей на GDScript с полным доступом к игре.

Ничего ставить не нужно: мод — это **папка с файлом `mod.json`**. Правите в любом текстовом редакторе, лаунчер подхватывает сам.

> English version: [../en/README.md](../en/README.md) · Справочник API (англ., собирается из кода): [../en/api-reference.md](../en/api-reference.md)

## Старт за пять минут

1. **Создайте мод.** В игре нажмите **F8** (консоль разработчика) и введите:
   ```
   new my_first_mod Мой первый мод
   ```
   Появится папка `mods/my_first_mod/`: `mod.json`, `main.gd`, переводы и `AGENTS.md` для ИИ-ассистентов.
   (Без запущенной игры: `godot --headless --path <игра> -- --new-mod my_first_mod`.)

2. **Добавьте планету.** Создайте `mods/my_first_mod/data/bodies.patch.json`:
   ```json
   {
     "bodies": {"$append": [{
       "name": "Нибиру", "genus": "rock", "r": 5200, "a": 420000000, "angle": 75, "open": true,
       "parameters": {"temperature": 0.2, "water": 0.3, "atmosphere": 0.4, "biomass": 0.0,
                      "radiation": 0.3, "urban": 0.0, "magnetic": 0.2}
     }]}
   }
   ```

3. Лаунчер → **Моды** — ваш мод в списке и включён (если лаунчер был открыт, нажмите «Моды» ещё раз). Играйте: Нибиру кружит между Марсом и Юпитером.

4. **Проверьте:** `check my_first_mod` в консоли F8 или
   `godot --headless --path <игра> -- --check-mods my_first_mod` (код выхода 0 — ошибок нет).

5. **Поделитесь:** `pack my_first_mod` → zip в `user://mods_dist`. Игрок кладёт zip в свою папку `mods` — распаковывать не нужно.

## Учитесь на работающих примерах

- **`example_theia`** — планета со своими картами цвета, рельефа и океанов, окно в нижней панели, запись в хронику
  каждые несколько перемоток и состояние в сейве. ~60 строк кода с комментариями.
- **`example_alpha_centauri`** — вторая звёздная система в 4,37 светового года (три звезды, планета-«глаз»
  Проксима b) и окно **Ковчеги**, которое запускает межзвёздные ковчеги из любой колонии.

Они лежат в `mods/` исходников игры и в `docs/modding/examples/` выпущенной игры (скопируйте в `mods/`, чтобы попробовать).

## Правила, которые экономят часы

1. **Правьте, а не копируйте.** Никогда не копируйте файл игры в мод целиком — используйте `*.patch.json`.
   Тогда мод уживётся с другими и переживёт обновления игры.
2. **Ключи данных — по-русски** (`"bodies"`, `"name"`, `"genus"`). Берите их точно из `data/*.json` игры;
   [схемы](../schemas) и это руководство объясняют каждый.
3. **Текст, который видит игрок, — в `data/lang/`**, минимум `ru.json` и `en.json`. Не вшивайте его в код.
4. **GDScript здесь строгий:** `var x := нетипизированное` — ошибка компиляции. Пишите `var x: float = d["a"]`.
5. **Проверяйте перед публикацией:** `--check-mods`.

## С ИИ-ассистентом (Claude Code, Cursor, Copilot…)

В каждом моде, созданном командой `new`, есть **`AGENTS.md`** (и `CLAUDE.md`, который на него ссылается): где что
лежит, правила выше и команда проверки. Откройте папку мода рядом с папкой игры и попросите:
*«Добавь систему красного карлика в 6 световых годах с двумя каменными планетами и кризисом при вспышках звезды»* —
потом пусть ассистент запустит `--check-mods` и исправит то, что найдёт проверка.
