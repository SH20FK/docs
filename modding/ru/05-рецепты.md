## Персонажи

Люди, которых игрок встречает и с кем говорит (озвучивает нейросеть). Добавляются из кода, когда это нужно по сюжету:

```gdscript
func _world_ready(game: PaxGame) -> void:
    if not game.has_character("Ада Рейн") and game.colonies().has("Марс"):
        game.add_character("Марс", {
            "name": "Ада Рейн",
            "who": tr_key("my_mod_ada_who"),
            "lore": tr_key("my_mod_ada_lore"),
            "character": tr_key("my_mod_ada_character"),
            "age": 41
        }, path("portraits/ada.png"))
```
Текстовые поля — это то, что читает нейросеть, играя человека: пишите их на языке игрока через `tr_key`.

## Лидеры

Кто приходит вместо игрока, когда доверие рухнуло, — `data/leaders.patch.json`:
```json
{"heads": {"$append": [{
  "name": "Ильзе Варга",
  "origin": "инженер гидропоники, прокормила колонию в первую зиму",
  "character": "тихая, упрямая, помнит каждое обещание",
  "first_word": "Покажите отчёты по воде. Потом поговорим."
}]}}
```

## Фракции

Случайные соседи на Земле — `data/factions.patch.json`. Скопируйте запись из `"strangers"` файла игры и поменяйте.
`тип` задаёт поведение: `банда`, `мародёры` (хищники), `секта` (хищная к мирным), `община`, `анклав`, `торговцы` (мирные).
Умыслы (`умыслы`, веса): `выжить`, `грабить`, `захватить_нас`, `культ`, `найти_родных`, `обложить_данью`,
`отомстить_олигархам`, `поработить`, `построить_дом`, `сохранить_знания`, `торговать`, `уйти_на_орбиту`.
```json
{"strangers": {"$append": [{
  "type": "sect",
  "colour": [0.55, 0.3, 0.8],
  "strength": [0.1, 0.2],
  "names": ["Дети Последнего Света", "Тихий Хор"],
  "description": "Верят, что война была очищением. Добры к чужакам, беспощадны к сомневающимся.",
  "humans": [60, 200], "level": [0.2, 0.8], "relations": 0.4, "growth": 0.01, "roam": false,
  "temper": {"wits": [0.3, 0.6], "cunning": [0.4, 0.8], "cruelty": [0.2, 0.7], "honesty": [0.3, 0.7], "cohesion": [0.8, 1.0]},
  "contingent": {"scientists": 0.05, "masters": 0.2, "fighters": 0.2, "laborers": 0.4, "children_elders": 0.15},
  "intents": {"cult": 5, "to_trade": 2}
}]}}
```

## События

Случайности при перемотке — `data/world_events.patch.json`. Списки `плохо`, `хорошо`, `смешанно`.
```json
{"good": {"$append": [{
  "scale": "science",
  "text": "студенты в месте «{место}» собрали довоенный спектрометр",
  "effect": {"scales": {"science": [0.3, 0.9]}, "trust": [0.01, 0.03]}
}]}}
```
- `шкала` — шкала развития: `сеть`, `жильё`, `инфраструктура`, `работа`, `добыча`, `наука` (пусто — любая).
  `{место}` заменится местом этой шкалы (из `"places"`).
- `нужно` (по желанию) — минимальные уровни шкал, например `{"jobs": 10}`.
- `эффект` — диапазоны `[мин, макс]`: `шкалы` (уровни), `ресурсы` (минус — доля склада, плюс — штук на человека),
  `доверие` (сдвиг), `люди` (доля населения), `климат` (сдвиг параметра).

События одного тела (с досье для нейросети) — в `data/events_bodies.json` → `"bodies"."<тело>"`.

## Кризисы

Угрозы в пять стадий — `data/crises.patch.json`:
```json
{"crises": {"$append": [{
  "id": "my_mod_flare",
  "name": "Звезда просыпается",
  "era": "technologies",
  "explanation": "магнитный цикл звезды — предсказуемый, но жестокий",
  "needs": {},
  "шанс_centuries": 15,
  "speed": 0.8,
  "resistance": ["science", "infrastructure"],
  "spread": 0.2,
  "how_to_fight_it": "экранированные убежища, запасные трансформаторы, сеть оповещения",
  "stages": [
    {"name": "Пятна", "what": "в полдень трещит радио"},
    {"name": "Вспышки", "what": "спутники слепнут на часы"},
    {"name": "Отключения", "what": "на дневной стороне горит сеть"},
    {"name": "Сезон бурь", "what": "без дозиметра наружу не выходят"},
    {"name": "Выжженное небо", "what": "дневную сторону бросили"}
  ]
}]}}
```
`эпоха` — когда может начаться: `руины`, `индустрия`, `технологии`, `любая`. `нужно` — минимальные уровни развития, например `{"comms": 8}`.

  "what_it_gives": "water"

## Музыка и звук

- **Музыка:** `.ogg`/`.mp3` в `mods/<id>/music/` с приставками игры — `надежда_` (спокойное), `тревога_`, `начало_`
  (новая игра), `контакт_` (первый контакт), `этап_` (веха), `кризис_`, `перемотка_`, `автоигра_`.
  Например `music/надежда_my_mod_1.ogg`. Треки вливаются в плейлисты игры.
- **Фоновые слои** (замена): `mods/<id>/ambient/<слой>.ogg`, слои: `космос`, `радиация`, `пустота`, `холод`,
  `жара`, `вода`, `океан`, `пустыня`, `живность`, `воздух`, `джунгли`, `город`.
- **Любой звук из кода:** `var p := AudioStreamPlayer.new(); p.stream = sound("sfx/alarm.ogg"); add_child(p); p.play()`.

## 3D-модели для приказов

Игрок приказывает «построить купол» — игра подбирает модель по словам, `data/models.patch.json`:
```json
{"models": {"$prepend": [{
  "file": "res://mods/my_mod/models/arcology.glb", "orbit": false, "size": 0.05,
  "words": ["аркология", "arcology"]
}]}}
```
`$prepend` — выигрывает первое совпадение, поэтому точные слова ставьте раньше. `орбита: true` — модель на орбите.

## Новый язык

1. Скопируйте `data/lang/en.json` игры в `mods/<id>/data/lang/<код>.json` (например `pl.json`) и переведите значения.
2. По желанию — имена людей: `data/names.patch.json` → `{"languages": {"pl": {"name_language": "Polish", "male": […], "female": […], "surnames": […]}}}`.
3. Имена тел — ключи `тело_<имя>` в том же словаре.
Язык появится в настройках лаунчера. Недостающие ключи возьмутся из английского.

## Научить нейросеть

Рассказчик работает по инструкциям `data/prompt_<канал>.txt`. Дописывайте правила своего мира через
`data/prompt_<канал>.append.txt` (не заменяйте — другие моды тоже дописывают):

| Канал | Роль |
|---|---|
| `interpreter` | Превращает приказы игрока в действия |
| `event` | Пишет события |
| `talk`, `person` | Разговоры и новые люди |
| `report`, `chapter`, `consequences` | Итоги перемотки и главы хроники |
| `faction`, `faction_order`, `council` | Фракции и совет |
| `province`, `unit`, `surroundings` | Провинции, отряды, окрестности |
| `epoch`, `god`, `successor`, `assistant` | Путешествия во времени, конец времён, преемники, помощник |

`mods/xeno_life/data/prompt_event.append.txt`:
```
В этом мире под льдом Европы и Энцелада есть микробная жизнь. События об этих лунах могут упоминать
биосигнатуры, но никогда — разумную жизнь.
```

## Пресет мира

Соберите мир в **редакторе пресетов** игры (фракции, земли, лор, дата старта), потом скопируйте его папку из
`user://presets/<Имя>/` в `mods/<id>/presets/<Имя>/`. У игроков он установится при запуске; чтобы обновить у тех,
у кого он уже есть, поднимите `"version"` в `meta.json`.

## Тема интерфейса

`data/ui_theme.patch.json` в моде — цвета и шрифт игры. Цвета заданы **ролями**: меняете роль — меняются все места,
где она используется.

```json
{
  "window": "#2a0f14",
  "panel": "#1a0a10",
  "text": "#ffe2a8",
  "quiet": "#c08a6a",
  "accent": "#5fe08a",
  "good": "#7ad1ff",
  "bad": "#ff5a8a",
  "alarm": "#ffb04a",
  "info": "#ffd24a",
  "special": "#d9a6ff",
  "size_text": 18,
  "font": "res://mods/my_mod/fonts/MyFont.ttf"
}
```

| Роль | Что красит |
|---|---|
| `окно`, `панель` | подложки окон, полос, карточек и кнопок |
| `текст`, `тихий` | основной и второстепенный текст |
| `акцент` | заголовки, выделение, нажатая кнопка, нить панелей (в игре — золото) |
| `хорошо`, `плохо`, `тревога` | зелёное, красное и оранжевое: «в силе», «отменить», предупреждения |
| `инфо`, `особое` | сведения (бирюзовое) и необычное (лиловое) |

Роли берут окна игры (законы, наука, добыча, входящие, контакты, власть, курс и другие), верхняя и нижняя полосы,
кнопки и цветной текст ленты событий. Прозрачность каждого места остаётся своей. Цвет — `"#rrggbb"` или `[r, g, b]`
в долях. Любого ключа может не быть — там останется вид игры. Английские имена ролей тоже работают: `window`, `panel`,
`text`, `muted`, `accent`, `good`, `bad`, `warning`, `info`, `special`, `font`, `font_size`.

Тему не берёт то, что рисует мир, а не интерфейс: карта и цвета стран, графики, значки ресурсов, трёхмерные фигурки.
Газета печатается на своей бумаге. Тема читается при запуске игры — после правки перезапустите партию.

## Свой календарь

Названия месяцев, эра и счёт лет своего мира — без кода. Файл мода `data/calendar.patch.json`:

```json
{
  "months": {
    "ru": ["Морозеня", "Вьюжня", "Талого", "Ручейника", "Цветеня", "Светлого", "Жарника", "Жатвеня", "Рыжего", "Листопада", "Туманника", "Тёмного"],
    "en": ["Frostmonth", "Stormmonth", "Thaw", "Brooks", "Bloom", "Bright", "Heat", "Harvest", "Rust", "Leaffall", "Mist", "Dark"]
  },
  "aeon": {"ru": "Э. Ф.", "en": "FE"},
  "shift_year": 0
}
```

- `месяцы` — ровно 12 названий в родительном падеже («3 Морозеня»); можно одним списком без языков.
- `эра` — подпись после года: «958 Э. Ф.».
- `сдвиг_года` — сколько прибавить к году на показе, если летоисчисление идёт от своего события.

Дата так выглядит везде: в шапке игры, в газете, в запросах к нейросети. Счёт дней, сезоны и орбиты не меняются —
в году по-прежнему 12 месяцев. Тот же блок можно положить в пресет полем `"calendar"` в `meta.json`: у пресета он
главнее. Год начала мира задаёт поле `"start"` пресета. Мир из Azgaar получает эру автоматически.
