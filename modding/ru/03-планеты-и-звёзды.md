# 03 · Планеты, луны, звёзды и звёздные системы

[← К руководству](README.md) · Схема: [`bodies.schema.json`](../schemas/bodies.schema.json)

Всё на небе берётся из `data/bodies.json`. Мод добавляет и меняет тела через `data/bodies.patch.json`.
Расстояния — **настоящие километры**; 1 единица сцены = 1000 км.

## Тело

```json
{
  "name": "Тея",
  "genus": "rock",
  "r": 4100,
  "a": 285000000,
  "angle": 40,
  "open": true,
  "sid": 7.3,
  "description": "Потерянная планета.",
  "parameters": {"temperature": 0.3, "water": 0.35, "biomass": 0.05, "radiation": 0.2,
                 "atmosphere": 0.4, "urban": 0.0, "magnetic": 0.3},
  "map": "res://mods/example_theia/planets/theia",
  "map_sea": 0.52
}
```

| Ключ | Значение |
|---|---|
| `имя` | **Id** и имя по умолчанию. Имя на языках — ключи `"тело_<имя>"` в `data/lang/<код>.json`. |
| `род` | `камень` (колонии, провинции, климат) · `газ` газовый гигант · `звезда` |
| `r` | Радиус, км (Земля 6371, Луна 1737, Юпитер 69911, Солнце 696000) |
| `a` | Радиус орбиты, км, вокруг родителя (`спутник`) или центра системы. Земля: 149 598 000. `0` — в центре. |
| `угол` | Начальное место на орбите, градусы. |
| `период` | Период обращения, дни. Вокруг звезды считается сам (Кеплер, масса звезды); **лунам новых планет задавайте**. |
| `спутник` | Id родителя. Луны и планеты второй звезды. Родитель должен стоять в списке **раньше**. |
| `система` | Звёздная система (см. ниже). Пусто — Солнечная. Луны наследуют. |
| `открыт` | Известно с начала. Неизвестные тела скрыты, пока их не разведают или не долетит корабль. |
| `параметры` | Шкалы климата 0..1 — от них зависят и симуляция, и шейдер планеты. `temperature` ~0.35 — как на Земле; `urban` > 0.01 — может появиться колония. |
| `цвет_породы` | `[r, g, b]` цвет камня для тел без карт. |
| `кольца` | `[внутр км, внеш км]` от центра. |
| `полос`, `цвета` | Газовые гиганты: число полос и три цвета `[r,g,b]`. |
| `провинций`, `провинции_имена` | Провинции каменных тел (см. ниже). |
| `дом` | Дом игрока. Одно тело — не ставьте, если не заменяете Землю. |

## Текстуры и рельеф

`"map"` называет набор карт в равнопромежуточной проекции (2:1, например 2048×1024 или 4096×2048):

| Файл | Что в нём |
|---|---|
| `<имя>_albedo.png` / `.jpg` / `.webp` | Цвет поверхности. |
| `<имя>_height.png` | Высота в оттенках серого: белое — высоко. Включает настоящий рельеф и уровень моря (`карта_море`, 0..1). |
| `<имя>_ocean.png` | Маска воды: **белое — вода**. Даёт блики океанов. |

- Короткое имя (`"mars"`) — карты игры: `res://maps/mars_albedo.jpg`.
- Путь со `/` — ваши файлы: `"res://mods/my_mod/planets/xeno"` → `xeno_albedo.png`, `xeno_height.png`…
- Файла нет — не страшно: без цвета поверхность процедурная, без высот — ровная.
- Картинки мода читаются на лету, импорт Godot не нужен.
- `"height_rainbow": 1` раскрашивает высоты радугой (безвоздушные тела, «научный» вид).

Совет: карты настоящих тел есть у NASA/USGS; ещё подойдут генераторы планет или нейросеть. Пример-мод делает свои
карты 40 строками Python + numpy (см. `example_theia`).

## Меняем существующие тела

```json
{"bodies": {
  "$edit":   [{"$match": {"name": "Марс"}, "parameters": {"water": 0.4, "atmosphere": 0.5}, "map": "res://mods/green_mars/mars"}],
  "$remove": [{"name": "Седна"}]
}}
```
Удалять тела, о которых говорит сюжет (Земля, Луна, Марс), опасно — лучше менять.

## Звёздные системы

Мод может поставить системы где угодно в галактике — одну соседнюю звезду или целое скопление.

```json
{
  "systems": {"$append": [{
    "name": "Альфа Центавра",
    "star": "Альфа Центавра A",
    "situation_sv_years": [-1.64, -1.37, -3.84],
    "mass": 1.1,
    "description": "Ближайшая звёздная система."
  }]},
  "bodies": {"$append": [
    {"name": "Альфа Центавра A", "genus": "star", "system": "Альфа Центавра", "r": 851000, "a": 0, "open": true,
     "shader_parameters": {"core": [1.0, 0.95, 0.8], "edge": [1.0, 0.62, 0.25]}},
    {"name": "Проксима Центавра", "genus": "star", "satellite": "Альфа Центавра A", "r": 107000,
     "a": 1940000000000, "period": 199800000, "open": true},
    {"name": "Проксима b", "genus": "rock", "satellite": "Проксима Центавра", "r": 7160, "a": 7260000, "period": 11.19,
     "map": "res://mods/example_alpha_centauri/planets/proxima_b", "open": true}
  ]}
}
```

Как это устроено:

- **Солнечная система — всегда система 0** в `[0, 0, 0]`; её перечислять не нужно.
- `положение_св_лет` — место относительно Солнца в световых годах. Годятся настоящие координаты: ближние звёзды —
  несколько св. лет, Плеяды — ~444.
- Тело выбирает систему через `"system"`; луны и планеты второй звезды наследуют её через `"satellite"`.
- `масса` (в солнечных) задаёт скорость обращения планет вокруг центра (Кеплер). Лунам задайте `"period"` явно.
- **Свет** идёт от своей звезды тела: планету Проксимы освещает Проксима, хотя главная звезда системы — A.
- Камера: «вид на систему» охватывает систему тела в фокусе; если отдалиться дальше, откроется карта галактики, где звезда вашей системы тоже стоит (дайте ей `"system"` в `galaxy.json`, иначе она будет только в сцене).
- Старение Солнца (красный гигант, сдвиг зоны жизни) касается только Солнечной системы.
- **Пояса астероидов** тоже могут принадлежать системе: `"belts": {"$append": [{"name": "…", "system": "Альфа Центавра", "inner": …}]}`.

Скопление — это просто много систем. Сгенерируйте их скриптом или ведите список вручную: каждая система — несколько тел.

### Галактика: у каждой звезды есть система

Если отдалиться за край системы, откроется **карта галактики** (клавиша U): Млечный Путь на 1000 звёзд, а дальше —
Местная группа. Андромеда — отдельная карта, по ней надо щёлкнуть. Войти можно в любую звезду: систему игра
строит при первом входе, а в сейв кладёт только «эта звезда открыта» (генерация детерминированная).

- `data/galaxy.json` — зерно, число звёзд, рукава, известные звёзды (`l`, `b`, `св_лет`), Местная группа. Сосед с
  `"key"` и `"stars_of"` становится своей галактикой, куда можно войти (как Андромеда). Известная звезда с `"system"`
  ведёт в готовую систему из `bodies.json` (Солнце или система вашего мода).
- `data/galaxy_systems.json` — настоящие планеты известных звёзд, ключ — английское имя звезды: `r_земли`, `a_ае`, `K`,
  `вода`, `атм`, `жизнь`, звёзды-спутники в `"stars"`. Известная звезда без записи получает сгенерированные планеты.
- `data/galaxy_secrets.json` — пасхалки в звёздах: своя планета (`"planet"` с внутренним `"name"`, перевод — ключ
  `тело_<имя>`), гости на орбите (`"guests"`) и на земле (`"on_earth"`, виды из `data/guests.json`). Без `"star"`
  игра сама выбирает звезду по классу и месту (`ядро`, `рукав`, `окраина`). Тексты: `гал_тайна_<id>` и `гал_тайна_<id>_текст`.

```json
{"mysteries": {"$append": [{"id": "my_secret", "galaxy": "млечный", "where": "окраина", "class": "K",
  "planet": {"name": "Моя планета", "type": "умеренная", "r_земли": 1.0, "a_ае": 0.8, "water": 0.5, "atm": 0.6},
  "guests": ["monolith_servers"]}]}}
```

В коде: `game.galaxy()`, `game.galaxies()`, `game.chart_star("млечный:17")`, `game.enter_star(...)`,
`game.charted_stars()`, `game.secrets_found()`; обратные вызовы `_system_charted`, `_secret_found`; хук
`system_generated` позволяет поправить или добавить тела сгенерированной системы до их создания.

### Ковчеги между звёздами

Перелёты — часть игры, а не только модов: `game.launch_ship(откуда, куда, скорость_c, люди)` — см.
[04 Код → Корабли и ковчеги](04-код.md#корабли-и-ковчеги). На 0,1 c до Проксимы b ~45 лет; ковчег видно летящим,
а по прилёте он основывает колонию.

## Шейдеры и модели

### Свой шейдер

```json
{"name": "Пульсар-7", "genus": "star", "r": 20, "a": 0, "system": "Паруса",
 "shader": "res://mods/my_mod/shaders/pulsar.gdshader",
 "shader_parameters": {"beam_color": [0.6, 0.8, 1.0], "spin": 30.0, "noise": "res://mods/my_mod/textures/noise.png"}}
```

- `шейдер` заменяет шейдер материала тела (Godot, `shader_type spatial`). Начните с `shaders/planet.gdshader`,
  `star.gdshader` или `gas.gdshader` игры, чтобы сохранить свет и параметры климата.
- `шейдер_параметры` — uniform'ы: число; `[r,g,b]` станет `vec3` или `source_color`; `[x,y,z,w]` — `vec4`;
  строка-путь — текстура (`sampler2D`).
- Каменным телам игра всё равно выставляет параметры климата (`temperature`, `water`, …) — объявите их, чтобы пользоваться.
- У звёзд встроены `core`, `edge` (цвета). У планет: `relief`, `map_albedo`, `use_map`, `rock_tint`, … (смотрите файлы шейдеров).

Из кода материал меняется когда угодно: `game.body_material("Марс").set_shader_parameter("relief", 0.03)`.

### Модель вместо шара

`"mesh": "res://mods/my_mod/models/asteroid.glb"` — любой glTF/GLB (1 единица = радиус тела). Астероиды,
искусственные миры, рои Дайсона, брошенные станции.

## Провинции

Каменные тела делятся на провинции (политическая карта, войны, освоение). Для тел из модов игра **сама нарезает
24 провинции** (кэш в `user://mod_cache/regions/`). Управлять можно так:

```json
{"name": "Тея", "provinces_count": 12,
 "provinces_names": [{"en": "Wind Valley", "ru": "Долина Ветров"}, "Красные Холмы", "…"]}
```
Безымянные станут *Regio I, II…*. Свои границы — `data/regions/тело_<имя>.json` + `.bin` в моде
(формат — `tools/провинции/без_карт.py` в исходниках игры).

## Чек-лист

- `check <id>` найдёт: неизвестных родителей и системы, наборы карт без `_albedo`, отсутствующие шейдеры и модели.
- `json res://data/bodies.json` — итоговый список.
- `eval game.body_names()`, `eval game.systems()` — в запущенной игре.
