# 02 · Правим данные игры

[← К руководству](README.md)

Почти всё в Pax Universe — данные: `data/*.json` и `data/*.txt` внутри игры. Мод меняет их **без копирования** —
кладёт в себя файл по тому же пути.

| Файл в моде | Что делает |
|---|---|
| `data/X.patch.json` | **Правка** `data/X.json`: слияние объектов, операции над массивами. ✅ Так и надо. |
| `data/X.json` | **Замена** файла целиком. ⚠ Конфликтует с другими модами и ломается при обновлениях. Проверка предупредит. |
| `data/lang/X.json` | Переводы **сливаются** со словарём игры (никогда не заменяют). |
| `data/X.append.txt` / `.append.md` | **Дописать** текст к `data/X.txt` / `.md` (промпты нейросети, новости). |
| `data/X.txt` | Заменить текстовый файл. |
| любой новый путь | Новый файл, который читает игра или ваш код, например `data/regions/xeno.json`. |

Правки всех включённых модов применяются по порядку загрузки. Итог в любой момент — команда консоли
`json res://data/bodies.json`.

## Формат правки

Правка — это **JSON Merge Patch** (RFC 7396) плюс операции над массивами.

### Объекты сливаются

```json
{"formulas": {"chance_project": "0.5 * покрытие"}, "устаревшее_поле": null}
```
Ключи сливаются вглубь; `null` удаляет ключ. Массивы **не** сливаются по номерам — для них операции:

### Операции над массивами

```json
{
  "bodies": {
    "$remove":       [{"name": "Плутон"}],
    "$edit":         [{"$match": {"name": "Марс"}, "r": 3500, "parameters": {"water": 0.3}}],
    "$insert_after": {"$match": {"name": "Земля"}, "items": [{"name": "Антиземля", "genus": "rock"}]},
    "$prepend":      [ … ],
    "$append":       [ … ]
  }
}
```

| Операция | Что делает |
|---|---|
| `$append` / `$prepend` | Добавить в конец / в начало. |
| `$edit` | Каждому элементу, подходящему под `$match`, влить остальные поля (вглубь). |
| `$remove` | Убрать подходящие. Можно объекты (частичное совпадение) или значения: `"$remove": ["a", 3]`. |
| `$insert_after` | Вставить `items` сразу после первого совпадения (один объект или список). |
| `$replace` | Заменить массив (или любой объект) целиком: `{"$replace": [...]}`. |

Порядок внутри одного объекта: `$remove → $edit → $insert_after → $prepend → $append`.

`$match` сравнивает только перечисленные ключи; список означает «любое из»: `{"$match": {"genus": ["gas", "star"]}}`.
Ничего не нашлось — правка идёт дальше, а мод получает **предупреждение** (карточка в лаунчере, `check`, консоль).
Операция над массивом, которого ещё нет, считает его пустым — так можно добавлять разделы, которых нет в файле игры
(например, `"systems"`).

## Файлы данных игры

Откройте файл игры, чтобы увидеть всё устройство: почти в каждом в начале есть `"_комментарий"` / `"_как_это_работает"`
с правилами.

| Файл | Что это | Главные ключи |
|---|---|---|
| `bodies.json` | Планеты, луны, звёзды, пояса, **звёздные системы** | `тела`, `пояса`, `системы` — см. [03](03-планеты-и-звёзды.md) |
| `bodies_lang.json` | Имена тел по языкам (старый формат; лучше ключи `тело_<имя>` в `lang/`) | `языки` |
| `resources.json` | Ресурсы, формулы, богатство тел | `ресурсы`, `формулы`, `тела.<тело>.богатство`, `колония` |
| `projects.json` | Мегапроекты | `проекты[]`: `имя`, `слова`, `цена`, `зачем`, `что_даёт` |
| `crises.json` | Кризисы в пять стадий | `кризисы[]`: `id`, `имя`, `эпоха`, `объяснение`, `шанс_века`, `скорость`, `сопротивление`, `стадии[]` |
| `world_events.json` | Случайные события при перемотке | `плохо[]`, `хорошо[]`, `смешанно[]`: `шкала`, `текст` с `{место}`, `эффект` |
| `events_bodies.json` | События и досье конкретных тел | `тела.<тело>.досье`, `события[]` |
| `development.json` | Уровни шкал развития колоний | `сеть`, `жильё`, `инфраструктура`, `работа`, `добыча`, `наука` |
| `factions.json` | Наша фракция и случайные соседи | `наша`, `чужие[]` |
| `leaders.json` | Кто приходит вместо свергнутого игрока | `главы[]`: `имя`, `откуда`, `характер`, `первое_слово` |
| `names.json` | Имена по языкам | `языки.<код>.мужские/женские/фамилии` |
| `markers.json` | Стартовые метки на карте | `метки[]`: `широта`, `долгота`, `тип`, `имя`, `описание` |
| `models.json` | 3D-модели, подбираемые по словам приказа | `модели[]`: `файл` (имя или путь `res://mods/…`), `слова`, `размер`, `орбита` |
| `satellites.json` | Искусственные спутники по датам | `спутники[]` |
| `epochs.json` | Эпохи машины времени | `эпохи[]` |
| `anomalies.json`, `prophecies.json` | Странности путешествий во времени и самосбывающиеся пророчества | |
| `start.json` | Стартовый климат и ресурсы | `параметры`, `ресурсы`, `склад` |
| `problems.json` | Стартовые беды и жалобы по состоянию | `стартовые[]`, `по_состоянию` |
| `preset_default.json` | Мир по умолчанию: лор, фракции, земли | `лор_системы`, `лор_тел`, `фракции`, `сюжет` |
| `prompt_*.txt` | Инструкции каналам нейросети | текст — дописывайте через `.append.txt` |
| `news/<код>.md` | «Что нового» в лаунчере | markdown |
| `lang/<код>.json` | Тексты интерфейса | плоский `ключ: текст` |
| `regions/*.json/.bin` | Провинции тел | собираются `tools/провинции` |

## Пример: мир пожёстче

`mods/hardcore/data/crises.patch.json`
```json
{"crises": {"$edit": [
  {"$match": {"id": "чума"}, "шанс_centuries": 60, "speed": 1.2}
]}}
```

`mods/hardcore/data/start.patch.json`
```json
{"resources": {"humans": 60}, "parameters": {"radiation": 0.7}}
```

## Советы

- **Без перезапуска:** поправили JSON — `reload` в консоли F8. То, что читается позже, возьмёт новое; уже построенное
  (тела в сцене) — после новой игры или перезапуска.
- **Что игра получила на самом деле:** `json <путь>` печатает итог после всех правок.
- **Правка к файлу, которого нет в игре?** Проверка предупредит — скорее всего, опечатка в имени.
- **Числа** в JSON для Godot дробные: `3` и `3.0` в `$match` совпадают.
