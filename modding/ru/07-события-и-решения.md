# 07 · События и решения без кода

Событие — карточка, которая выпадает сама, когда выполнены условия: засуха, делегация, забастовка, находка археологов. У события есть варианты, у каждого варианта — эффекты.
Решение — кнопка в окне **«Решения»** в нижней панели: игрок сам принимает его, платит цену и получает эффект.

Всё пишется в одном файле мода `data/mod_events.patch.json`. Ни строчки кода. Готовый пример — мод `example_events` (в игре: `docs/modding/examples/example_events`).

## Файл

```json
{
  "events": {"$append": [ { …событие… } ]},
  "decisions": {"$append": [ { …решение… } ]}
}
```

`$append` добавляет ваши записи к записям других модов — так моды не мешают друг другу. У каждой записи уникальный `id`: начинайте его с id своего мода.

## Событие

```json
{
  "id": "my_mod_drought",
  "title": {"ru": "Засуха", "en": "Drought"},
  "text": {"ru": "Третью неделю ни капли.", "en": "Not a drop for three weeks."},
  "picture": "res://mods/my_mod/drought.png",
  "conditions": {"resource": {"food": {"меньше": 500}}},
  "шанс_v_year": 0.8,
  "times": 3,
  "options": [
    {"text": {"ru": "Открыть резерв", "en": "Open the reserve"},
     "conditions": {"money": {"не_меньше": 200}},
     "effects": {"money": -200, "resources": {"food": 300}}},
    {"text": {"ru": "Пусть справляются", "en": "Let them manage"},
     "effects": {"flag": "my_mod_ignored"}}
  ]
}
```

| Поле | Что значит |
|---|---|
| `id` | уникальное имя |
| `заголовок`, `текст` | строка, словарь по языкам `{"ru": …, "en": …}` или `"@ключ"` из ваших `data/lang/*.json` |
| `картинка` | необязательно: png или jpg из мода |
| `условия` | когда событие может случиться (ниже) |
| `шанс_в_год` | шанс за год игрового времени, 0…1; по умолчанию 1 — как только условия выполнены |
| `раз` | сколько раз за партию; `0` — без ограничения; по умолчанию 1 |
| `эффекты` | срабатывают сразу, до выбора |
| `варианты` | кнопки; вариант с невыполненными `условия` не показывается. Без вариантов событие просто пишется в хронику |
| `только_цепочкой` | `true` — событие само не выпадает, его зовут эффектом `"event"` |

## Решение

```json
{
  "id": "my_mod_public_works",
  "title": {"ru": "Народная стройка", "en": "Public works"},
  "text": {"ru": "Нанять безработных на дороги.", "en": "Hire the unemployed to build roads."},
  "price": 300,
  "seen": {"at_war": false},
  "conditions": {"money": {"не_меньше": 300}},
  "rollback_days": 180,
  "times": 0,
  "effects": {"resources": {"materials": 250}}
}
```

`видно` — когда решение вообще есть в списке; `условия` — когда кнопка активна; `цена` — деньги; `откат_дней` — сколько ждать до повтора; `раз` — сколько раз за партию (`0` — сколько угодно).

## Условия

Все условия в словаре должны выполниться. Числа сравниваются словарём `{"больше": 1, "меньше": 5, "не_меньше": 1, "не_больше": 5, "равно": 3}` (можно и по-английски: `more`, `less`, `at_least`, `at_most`, `equals`) или просто числом — тогда «не меньше».

| Условие | Пример |
|---|---|
| `после`, `до` | `"after": "1941-06-22"` |
| `страна` | `"country": "Россия"` или список |
| `деньги` | `"money": {"больше": 1000}` |
| `ресурс` | `"resource": {"food": {"меньше": 500}, "fuel": 100}` |
| `война` | `true` — идёт любая, `false` — мир, `"Франция"` — с ней |
| `отношение` | `"relations": {"Франция": {"меньше": 0.3}}` (0 — враги, 1 — союзники) |
| `закон` | действующий закон, в названии которого есть слово: `"law": "conscription"` |
| `форма` | ключ формы власти из `data/politics/forms.json` |
| `флаг`, `нет_флага` | флаги, которые ставят эффекты |
| `мод` | включён ли другой мод: `"mod": "example_theia"` |
| `шанс` | случайность при проверке: `0.3` |
| `любое` | список наборов условий, хватит одного: `"любое": [{"country": "США"}, {"at_war": true}]` |
| `не` | набор условий, который НЕ должен выполниться |

## Эффекты

| Эффект | Пример |
|---|---|
| `деньги` | `"money": -200` |
| `ресурсы` | `"resources": {"food": 300, "materials": -50}` |
| `отношение` | `"relations": {"Франция": 0.1}` |
| `флаг`, `снять_флаг` | `"flag": "my_mod_x"` |
| `хроника` | `"chronicle": {"text": {"ru": "…"}, "tone": "good", "weight": 3}` (тон: good, bad, mixed, neutral) |
| `сообщение` | короткая строка в ленте |
| `объявить_войну` | `"declare_war": "Франция"` |
| `провинция` | `"province": {"id": 1368, "owner": "Франция"}` — вместо номера `"случайная"` или страна; владелец `""` — ничья |
| `кратер` | `"кратер": {"province": "случайная", "radius": 300}` — удар по воксельным копиям планеты, см. [09 Воксели](09-воксели.md) |
| `событие` | показать другое событие по `id` — так строятся цепочки |

## Свои условия и эффекты

Если слов не хватает, мод с кодом добавляет свои — и ими пользуются все JSON-моды:

```gdscript
func _mod_loaded() -> void:
    Pax.register_condition("my_mod_winter", func(v, game): return bool(v) == (game.date().month in [12, 1, 2]))
    Pax.register_effect("my_mod_ark", func(v, game): game.launch_ship(game.home_body(), str(v), 0.05, 500))
```

Проверить событие, не дожидаясь его: консоль **F8** → `eval Pax.fire_event("my_mod_drought")`.

Флаги, счётчики событий и откаты решений сохраняются в сейве сами.
