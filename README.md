# ВИ-Советник 2.0 (`strategist`)

**ВИ-Советник 2.0** — стратегический ИИ-советник и аналитический центр для *Pax Universe*.
Мод интегрируется со штатной языковой моделью игры, анализирует геополитическую обстановку, строит многошаговые дорожные карты, симулирует исходы военных конфликтов и помогает держать генеральную линию развития державы.

---

## 🌟 Ключевые возможности версии 1.1.0

### 1. 📌 Мини-индикатор цели на HUD (`ui/hud_widget.gd`)
- Компактная панель в верхней части экрана.
- Отображает профиль советника, название активной стратегии и текущий шаг в формате `★ План: «Вернуть Крым» [Шаг 2/4: Стянуть резервы]`.
- Кнопка быстрого вызова аналитического окна в один клик.

### 2. ⚔ Военный симулятор и калькулятор шансов (`lib/simulator.gd`)
- В досье любой державы на вкладке «Карта» выводится детальная оценка военной кампании:
  - **Шанс победы** (0–100%) с цветовой индикацией.
  - **Баланс сил** по провинциям и экономике (например, `1.45x`).
  - **Прогноз длительности** войны в днях.
  - **Риск удара коалиции** в спину со стороны союзников и пограничных врагов цели.
  - Аналитический вердикт штаба.

### 3. 🛡 Государственные доктрины (`lib/doctrines.gd`)
- Выбор долгосрочного курса развития на 10–25 лет:
  1. **«Крепость Держава»** — самообеспечение, глухая оборона границ, стратегические запасы.
  2. **«Космический прорыв»** — технологический рывок, колонии на Луне и планетах, постройка межзвёздных ковчегов.
  3. **«Континентальная гегемония»** — военное доминирование, подчинение соперников, пояс буферных сателлитов.
- Доктрина напрямую передаётся в системный контекст ИИ и формирует фокус всех предлагаемых планов.

### 4. ⚡ Операции в один клик (Direct Orders)
- Рекомендации советника на вкладке «Советы» теперь снабжены кнопкой **«⚡ Отдать приказ»**:
  - Быстрое объявление войны или приведение армии в боеготовность.
  - Направление посольств для улучшения отношений.
  - Все решения фиксируются в Летописи.

### 5. 🌐 Геополитическая матрица с дипломатическими лучами (`lib/map_view.gd`)
- 4 тактических сектора: *Главные угрозы*, *Союзники*, *Цели для экспансии*, *Буферные державы*.
- При выборе державы на матрице динамически отрисовываются векторные лучи союзов и коалиций.

### 6. 🚀 Оптимизация ядра (Event-Driven State & Spatial Cache)
- **Шина сигналов `Store`**: UI обновляется мгновенно по событиям без лишних перерисовок.
- **Пространственный кэш границ**: ускорение перемотки времени на длинных дистанциях в 3–5 раз.

## ⚙ Консольные команды отладки

Откройте консоль игры (`~` или `F1`) и используйте команду:
- `strategist eval` — статус базы держав и активной доктрины.
- `strategist brief` — вывод текущего стратегического брифинга для ИИ.
- `strategist plan` — принудительный запрос на составление плана.
- `strategist order` — тестовая отправка приказа.
